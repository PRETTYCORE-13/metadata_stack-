# SPEC-SYS-2509202603 — Jerarquía organizacional

**Documento:** Usage · Cómo usar la pantalla ya construida
(`/sysadmin/jerarquia`).

## Requisito

Necesitas el permiso "Jerarquía organizacional" (capacidad
`sysadmin_jerarquia`, ver `02.design.md` §4). Sin él, el ítem de menú
no aparece y la URL directa queda bloqueada.

## Paso a paso

1. Entra por el menú de Sysadmin → **Jerarquía organizacional**, o
   navega directo a `/sysadmin/jerarquia`.
2. **Columna izquierda (Empresas):** elige una empresa haciendo clic
   en su nombre. Si necesitas corregir la razón social, usa el ícono
   de lápiz junto al nombre — abre un form inline con solo el campo
   "Razón social". (Dar de alta o eliminar una empresa se hace en
   `/sysadmin/empresas`, no acá.)
3. **Columna central (Sucursales):** con una empresa elegida, aparecen
   sus sucursales. "+ Nueva" abre un form con el nombre de la
   sucursal; "Editar" (ícono de lápiz) permite corregirlo. No hay
   opción de eliminar una sucursal desde esta pantalla.
4. **Panel derecho (Unidades de venta / Ubicaciones de inventario):**
   con una sucursal elegida, aparecen lado a lado sus dos listas:
   - **Unidades de venta** — "+ Nueva" pide nombre (obligatorio) y tipo
     (libre, ej. "preventa", "autoventas", "pdv", "call center").
     "Editar"/"Eliminar" por cada renglón (Eliminar pide confirmación).
   - **Ubicaciones de inventario** — "+ Nueva" pide nombre
     (obligatorio), tipo (libre, ej. "planta", "punto de embarque",
     "almacén") y función (libre, ej. "comprometida", "producto
     terminado", "producción"). Mismas acciones de Editar/Eliminar.
5. Cambiar de empresa o de sucursal actualiza las listas de abajo al
   instante — no hace falta recargar la página.

## Notas

- Los campos de "tipo" y "función" son texto libre a propósito: no
  hay una lista cerrada de valores válidos todavía.
- Eliminar una Unidad de venta o Ubicación de inventario es
  inmediato (baja lógica) — no valida si algo más las está usando.
- Esta pantalla no asigna la jerarquía a ningún usuario ni a ninguna
  configuración — solo mantiene el catálogo base. Para asignar
  Alcance de Datos a un usuario, ver `/sysadmin/usuarios`.
