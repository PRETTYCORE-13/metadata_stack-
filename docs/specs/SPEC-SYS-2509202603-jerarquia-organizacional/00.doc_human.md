# SPEC-SYS-2509202603 — Jerarquía organizacional

**Documento:** doc_human · **Estado:** documentación retroactiva (la
funcionalidad ya está construida y en uso).

Cada empresa (cliente) que usa el sistema no opera como un bloque
único: tiene sucursales, y cada sucursal reparte su operación en dos
frentes distintos — dónde vende (Unidades de venta: preventa,
autoventas, punto de venta, call center) y dónde guarda su inventario
(Ubicaciones de inventario: planta, almacén, punto de embarque). Antes
de agosto de 2026 esa estructura no existía dentro del sistema como
tal — vivía repartida en configuraciones sueltas. La Jerarquía
organizacional es el catálogo base que representa esos cuatro niveles
dentro de la plataforma: Empresa → Sucursal → (Unidad de venta /
Ubicación de inventario), estas dos últimas hermanas entre sí, no una
adentro de la otra.

Esta pantalla es para quien administra la estructura del cliente
(típicamente un Sysadmin o un administrador de la empresa con el
permiso correspondiente): da de alta las sucursales de una empresa, y
dentro de cada sucursal, sus unidades de venta y ubicaciones de
inventario. Es un catálogo de base, no una pantalla operativa del
día a día — se toca cuando el cliente abre una sucursal nueva, agrega
un almacén, o crea una nueva unidad de venta, no en cada transacción.

El flujo, contado de punta a punta: un administrador entra a
"Jerarquía organizacional" desde el menú de Sysadmin, ve la lista de
empresas a la izquierda y elige una (o corrige su nombre ahí mismo, si
hace falta). Al elegir una empresa aparecen sus sucursales en la
columna del medio, donde puede agregar una sucursal nueva o corregir
el nombre de una existente. Al elegir una sucursal, aparecen — lado a
lado, a la derecha — sus Unidades de venta y sus Ubicaciones de
inventario, cada una con su propia alta, edición y baja. Todo queda
guardado con la trazabilidad estándar del sistema (quién y cuándo lo
creó, editó o dio de baja).

Esta jerarquía es la base sobre la que se paran otras dos cosas —
ninguna de las dos es parte de esta spec, solo se apoyan en las mismas
tablas: (1) el Alcance de Datos que se le asigna a cada usuario
(qué empresas/sucursales/almacenes/unidades de venta puede ver u
operar), y (2) la Configuración de Sales Unit para la app móvil, que
asigna un perfil de parámetros a cada Unidad de venta o Almacén real
de este catálogo.
