# SPEC-SYS-2509202603 — Jerarquía organizacional

**Documento:** Requirements · **Estado:** documentación retroactiva de
comportamiento ya implementado (Fase 0 del modelo de Alcance de Datos,
2026-08-11, con el agregado de edición de nombre de Empresa desde acá,
2026-09-11). No hay requisitos nuevos ni propuestos en este documento.

## 1. Acceso a la pantalla

R1. EL SISTEMA DEBE exponer la Jerarquía organizacional en una pantalla
propia (`/sysadmin/jerarquia`), accesible desde el menú de Sysadmin
bajo el ítem "Jerarquía organizacional".

R2. CUANDO un usuario no tiene el permiso de lectura sobre "Jerarquía
organizacional", EL SISTEMA DEBE ocultarle el ítem de menú
correspondiente y bloquear el acceso directo a la pantalla.

## 2. Empresas

R3. EL SISTEMA DEBE listar, en la columna izquierda de la pantalla,
todas las empresas vivas (no dadas de baja), en orden alfabético por
nombre.

R4. EL SISTEMA DEBE permitir editar el nombre (razón social) de
cualquier empresa listada, desde esta misma pantalla, sin tener que
navegar a la pantalla de Empresas.

R5. Esta pantalla NO expone alta ni baja de empresas — esas acciones
viven en la pantalla de Empresas (`/sysadmin/empresas`), fuera de
alcance de este documento.

## 3. Sucursales

R6. CUANDO se selecciona una empresa, EL SISTEMA DEBE listar, en la
columna central, sus sucursales vivas, en orden alfabético por nombre.

R7. EL SISTEMA DEBE permitir dar de alta una sucursal nueva dentro de
la empresa seleccionada, identificada por un nombre.

R8. EL SISTEMA DEBE permitir editar el nombre de una sucursal
existente.

R9. Esta pantalla NO expone baja de sucursales — la capacidad existe
en el sistema (bloqueada si la sucursal todavía tiene alguna Unidad de
venta o Ubicación de inventario viva), pero no está conectada a ningún
botón en esta UI.

R10. CUANDO se selecciona una empresa distinta, EL SISTEMA DEBE
limpiar la sucursal seleccionada previamente y sus listas dependientes
(Unidades de venta, Ubicaciones de inventario).

## 4. Unidades de venta y Ubicaciones de inventario

R11. CUANDO se selecciona una sucursal, EL SISTEMA DEBE mostrar, lado a
lado, dos listas independientes: sus Unidades de venta y sus
Ubicaciones de inventario vivas, ambas en orden alfabético por nombre.

R12. EL SISTEMA DEBE permitir dar de alta una Unidad de venta dentro de
la sucursal seleccionada, con un nombre obligatorio y un tipo de texto
libre y opcional (ej. preventa, autoventas, punto de venta, call
center — no es una lista cerrada).

R13. EL SISTEMA DEBE permitir dar de alta una Ubicación de inventario
dentro de la sucursal seleccionada, con un nombre obligatorio y dos
campos de texto libre y opcionales: tipo (ej. planta, punto de
embarque, almacén) y función (ej. comprometida, producto terminado,
producción) — ninguno de los dos es una lista cerrada.

R14. EL SISTEMA DEBE permitir editar el nombre y los campos libres de
cualquier Unidad de venta o Ubicación de inventario existente.

R15. EL SISTEMA DEBE permitir dar de baja (baja lógica) cualquier
Unidad de venta o Ubicación de inventario existente, pidiendo
confirmación antes de ejecutarla.

R16. A diferencia de la baja de una Sucursal (R9), la baja de una
Unidad de venta o Ubicación de inventario NO valida dependencias —
son hojas de la jerarquía, no tienen hijos propios en este modelo.

## 5. Integridad de datos

R17. CUANDO se crea una Unidad de venta o una Ubicación de inventario,
EL SISTEMA DEBE guardar tanto la referencia a su Sucursal como a la
Empresa dueña de esa sucursal (denormalizado), para no depender de un
`join` al resolver a qué empresa pertenece una hoja de la jerarquía.

R18. Toda alta, edición o baja en esta jerarquía (Empresa, Sucursal,
Unidad de venta, Ubicación de inventario) DEBE quedar registrada con
la misma trazabilidad estándar del sistema (usuario/momento de alta,
última edición, y baja si aplica).

## 6. Fuera de alcance de esta spec

- Alta y baja de Empresas (pantalla `/sysadmin/empresas`).
- La asignación de Alcance de Datos por usuario (qué
  empresas/sucursales/almacenes/unidades de venta puede ver u operar
  cada usuario) — documentada en `SPEC-SYS-1709202601-sysadmin-
  usuarios` y `SPEC-SYS-1109202605-bc-motor-tab-permisos-alcance`.
- El selector de "Unidad Operativa" que cada usuario activa en su
  sesión (empresa/sucursal/almacén/unidad de venta activos mientras
  trabaja) — es un consumidor de este catálogo, no parte de esta
  pantalla.
- La Configuración de Sales Unit para la app móvil
  (`SPEC-ADN-2209202601-config-sales-unit`), que asigna un perfil de
  parámetros a una Unidad de venta o Almacén real de este catálogo.
