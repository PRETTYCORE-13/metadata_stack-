## 1. Objetivo

Ver, como un gráfico de cajas y flechas, el flujo completo de estados y
transiciones que ya se configuró en el tab Configuración (ver
`SPEC-SYS-1109202601-bc-motor-tab-configuracion`) — sin tener que
armarlo mentalmente leyendo dos tablas separadas.

## 2. ¿Quién utiliza esta funcionalidad?

Gente de ADN o del equipo de plataforma, revisando el flujo de estados
de un catálogo desde el Motor BC (`/sysadmin/bc-list/:tabla/motor` →
tab "Diagrama"). Mismo público que el tab Configuración.

## 3. Conceptos que debo conocer

- El tab es de solo lectura: no tiene ningún control de edición propio,
  solo dibuja lo que ya existe en Estados/Transiciones.
- El dibujo se arma completo desde cero en cada carga — nunca es un
  ajuste incremental sobre el dibujo anterior.
- Un catálogo "detalle" nunca tiene este tab (no tiene autómata
  propio).

## 4. Flujo general

1. Abrir el tab Diagrama de un catálogo que no es detalle.
2. Esperar a que el gráfico termine de dibujarse ("Cargando diagrama…"
   mientras tanto).
3. Revisar el flujo: cajas = estados, flechas = transiciones (con el
   nombre de la acción como etiqueta), flecha especial sin origen =
   punto de entrada del estado inicial.

## 5. Guía paso a paso

### 5.1 Ver el diagrama

1. Entrar a `/sysadmin/bc-list/:tabla/motor` del catálogo.
2. Click en el tab "Diagrama".
3. El sistema arma y dibuja el gráfico automáticamente — no hay ninguna
   acción manual para disparar el dibujo.

### 5.2 Confirmar que un cambio se refleja

1. Con el tab Diagrama abierto, ir al tab Configuración y modificar un
   estado o una transición (o volver al tab Diagrama sin recargar la
   página después de un cambio).
2. El gráfico debería redibujarse solo con el cambio nuevo, sin
   necesitar F5 (ver nota de verificación pendiente en §8).

## 6. Ejemplos prácticos

### Ejemplo: un estado con color configurado

Si un estado tiene un color asignado en la tabla de Estados del tab
Configuración, su caja en el diagrama aparece pintada con ese mismo
color, con el texto en blanco o negro según lo que se lea mejor sobre
ese fondo — no hace falta configurar nada aparte en el diagrama.

## 7. Casos comunes

- **"El diagrama se queda en 'Cargando diagrama…'"** — puede ser que la
  librería que dibuja el gráfico no haya podido cargar (revisar la
  consola del navegador); si el dibujo en sí falla, el texto cambia a
  "No se pudo dibujar el diagrama.".
- **"No veo el tab Diagrama"** — el catálogo es un catálogo detalle;
  nunca tiene este tab, su flujo de estados es el de su maestro.

## 8. Errores y situaciones especiales

- Si Mermaid (la librería que dibuja el gráfico) falla al renderizar,
  aparece el texto "No se pudo dibujar el diagrama." y el error queda
  registrado en la consola del navegador para diagnóstico — nunca queda
  la pantalla vacía o congelada sin explicación.
- **Pendiente de confirmar en vivo (2026-09-11)**: el redibujado
  automático al editar una transición con el tab Diagrama abierto (R10)
  tiene el fix ya implementado y el bundle de JavaScript regenerado,
  pero la confirmación interactiva en navegador real todavía no se hizo
  (sin navegador headless disponible en el entorno de esa
  verificación) — queda para la próxima vez que se abra el Motor BC de
  un catálogo real. Si al probarlo el diagrama NO se redibuja solo, es
  la señal de revisar esto primero.

## 9. Resultado esperado

El diagrama muestra exactamente los estados y transiciones vivos
configurados en el tab Configuración, con los colores correspondientes,
y se mantiene actualizado si algo cambia sin necesitar recargar la
página (sujeto a la confirmación pendiente de §8).
