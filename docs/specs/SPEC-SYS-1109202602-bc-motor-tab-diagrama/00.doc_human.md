# SPEC-SYS-1109202602 — BC Motor: Tab Diagrama

**Documento:** Explicación general · **Fase:** ✅ aprobada (2026-09-11).

## ¿Qué problema resuelve?

Una vez que alguien arma en el tab "Configuración" los estados y
transiciones de un catálogo, es difícil visualizar de un vistazo todo el
flujo completo con solo leer dos tablas separadas. El tab "Diagrama"
resuelve eso: dibuja automáticamente ese mismo flujo como un gráfico (un
mapa de cajas y flechas), para verlo de una sola mirada, sin tener que
armarlo mentalmente.

## ¿Cómo funciona, a grandes rasgos?

Este tab es de solo lectura — no tiene ningún control para editar nada,
solo dibuja lo que ya existe. Cada vez que se entra al tab (o que algo
cambia en Estados/Transiciones mientras el tab sigue abierto), el
sistema arma de nuevo el dibujo completo a partir de todos los estados y
transiciones vivos del catálogo — nunca a partir de lo que se veía
antes, siempre desde cero.

Cada estado aparece como una caja con su nombre y su orden. Si un estado
tiene un color asignado (el mismo que se ve en la tabla de Estados del
tab Configuración), esa caja se pinta con ese color, y el sistema elige
automáticamente si el texto va en blanco o en negro para que siga siendo
legible. Cada transición aparece como una flecha entre dos cajas, con el
nombre de la acción como etiqueta. El punto de entrada al flujo (el
estado inicial) se marca con una flecha especial que no sale de ninguna
caja.

Mientras el dibujo todavía se está armando, aparece el texto "Cargando
diagrama…"; si algo sale mal y no se puede dibujar, aparece un aviso
claro en vez de dejar la pantalla congelada o vacía.

## Historia

En un principio, si alguien tenía el tab Diagrama abierto y editaba una
transición desde el tab Configuración (sin recargar la página), el
dibujo no se actualizaba solo — había que apretar F5 para ver el cambio
reflejado. Se corrigió: ahora el dibujo se redibuja solo apenas hay un
cambio real, sin necesitar recargar la página.

## ¿Quién usa esta funcionalidad?

Gente de ADN o del equipo de plataforma que arma o revisa el flujo de
estados de un catálogo desde el Motor BC — mismo público que el tab
Configuración, del que este tab es un complemento visual.

## Lo que esta spec NO hace

No permite editar estados ni transiciones — eso se hace desde el tab
"Configuración" (ver `SPEC-SYS-1109202601-bc-motor-tab-configuracion`),
este tab solo dibuja el resultado. Tampoco documenta el tab "Contrato"
(ver `SPEC-SYS-1109202603-bc-motor-tab-contrato`) ni ningún otro tab del
Motor BC.
