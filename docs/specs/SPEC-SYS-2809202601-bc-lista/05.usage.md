# SPEC-SYS-2809202601 — BC Lista: cómo se usa

**Documento:** Usage · Actualizado 2026-09-28.

## Entrar

Menú de usuario → **Sysadmin** → **BC List** (`/sysadmin/bc-list`).
Hace falta el permiso de lectura de Sysadmin sobre Business Contexts
(R1).

## Encontrar un artefacto

1. La tabla muestra el mismo árbol que el menú lateral. Todas las
   carpetas arrancan cerradas; haz clic en el nombre de una carpeta para
   abrirla o cerrarla.
2. Para buscar, escribe en **Buscar por nombre o etiqueta...**. La tabla
   se filtra sola al dejar de escribir y conserva las carpetas donde
   está lo que buscas (R6, R7).
3. Si hay más de 30 carpetas principales, usa las flechas de página
   junto a los botones de crear (R8).

Cada renglón muestra el nombre de sistema, la etiqueta, la ruta en el
menú (el ícono de la derecha la copia) y si está **Visible** u
**Oculto**.

## Crear y ordenar

| Botón | Para qué |
|---|---|
| **+ Carpeta** | Directorio nuevo que aparece en el árbol del menú lateral. |
| **+ Catálogo** | Transacción nueva (alta, baja, cambio, con su API). Abre el asistente. |
| **+ Ecto** | Consulta sobre una o más tablas. Ver SPEC-SYS-2509202602. |
| **+ SQL View** | Vista de base de datos para filtros especiales o reportes. Ver SPEC-SYS-2509202601. |
| **Vista** | Reordenar el árbol arrastrando y soltando. Cada suelta se guarda en ese momento. |

Cada carpeta principal tiene también su propio **Vista**, para
reordenar solo su contenido.

## Acciones de cada renglón

- **Editar**: abre el editor que le corresponde (BC Motor, Consulta o
  SQL View). En una carpeta, abre su formulario de etiqueta, ícono y
  visibilidad.
- **Copiar**: solo en catálogos simples. Ver SPEC-SYS-1809202602.
- **Eliminar**:
  - Catálogo: primero ves cuántos registros se perderían y si otro
    catálogo depende de él (en ese caso no se puede). Para confirmar,
    escribe el nombre exacto. Si es `pty_*` o `demo100_*`, enseguida
    se te ofrece despublicarlo de un sistema.
  - Carpeta: solo si está vacía.
  - Consulta o SQL View: confirmación simple.

## Publicar paquete

1. Al entrar, la tabla aparece de inmediato. En el encabezado de la
   primera columna gira un pequeño círculo mientras el sistema revisa
   qué catálogos están listos para publicarse (R20).
2. Cuando termina, los catálogos listos muestran una casilla. Los
   detalles nunca la muestran: viajan con su maestro (R16).
3. Marca uno o más y haz clic en **Publicar paquete (N)**.
4. Si algún catálogo marcado dejó de estar listo (por ejemplo, lo
   editaste en otra pestaña), se quita de la selección y un aviso te
   dice cuál. Si no queda ninguno, el modal no se abre (R24).
5. En el modal revisa el paquete completo, elige el sistema destino
   (`unstable` para una primera validación, o un sistema dado de alta)
   y confirma. El modal no se puede cerrar mientras publica (R17–R19).

Buscar o abrir carpetas no vuelve a revisar nada. La revisión se
repite sola al crear o eliminar algo desde la pantalla, cuando otro
usuario crea o cambia un artefacto, y después de publicar (R22, R23).

## Si aparece "No se pudo revisar qué catálogos están listos…"

La revisión falló por un error inesperado (queda registrado en el log
del servidor). La tabla funciona igual, solo sin casillas de
publicar. Recarga la página para intentarlo de nuevo (R25).
