# SPEC-ARQ-3009202601 — Purgar artefactos

**Documento:** Guía de uso · Grupo A verificado (2026-09-30). Retirar,
purgar y la bitácora ya están construidos (Grupos B-G), pero se
documentan aquí hasta verificarlos contra los ambientes reales (Grupo I).

## 1. Objetivo

Quitar artefactos `pty_*` de prueba de cualquier ambiente, como si nunca
hubieran existido.

## 2. ¿Quién utiliza esta funcionalidad?

Un super_admin que además tenga el rol de sistema
`acceso_sysadmin_purgar`. Solo existe donde corre el Business Process
Builder (máquina de cada desarrollador), nunca en producción.

## 3. Dar acceso a alguien

1. Configuración › Permisos Usuarios (`/sysadmin/usuarios`).
2. Elegir al usuario y abrir la pestaña **Sysadmin**.
3. Encender el switch **Purgar artefactos**.

Para ver la opción en el menú, el usuario también tiene que ser
super_admin (ver `02.design.md` §2).

## 4. Abrir la pantalla

Configuración › **Developer** › **Purgar** (`/sysadmin/purgar`).

- Pestaña **Artefactos** (`?pestana=artefactos`, la de entrada).
- Pestaña **Bitácora** (`?pestana=bitacora`).
